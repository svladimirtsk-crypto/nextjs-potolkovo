База этапа: `c06af58d1f84934e839f0d5949037592bbbaa39c` (завершённые главная/ребрендинг и калькулятор).

**Статус: реализовано и проверено в локальном безопасном preview. Не production-релиз. Коммерческая и инженерная готовность SMART не подтверждена.**

## Реализовано

- Каталог в палитре ПОТОЛКОВО: категории слева на desktop, доступная сетка категорий на mobile, поиск, счётчик результатов, четыре порядка сортировки, единая панель корзины.
- Категории поддерживают стрелки, Home/End и roving tabindex. Все основные фильтры переносятся по строкам без обязательного горизонтального свайпа.
- Поиск по названию/артикулу охватывает весь активный раздел, включая другой тип/систему/цоколь; вторичные фильтры при поиске не ограничивают выдачу, это объяснено в интерфейсе. Совпадения других разделов доступны отдельными переходами с сохранением запроса. SMART остаётся фильтром и для этих подсказок.
- Исправлена проверка `searchMatchesBySection.length` (число аргументов функции вместо длины массива результатов). Пустая подсказка «Найдено ещё» больше не показывается.
- Сортировка: исходный порядок с фото, цена по возрастанию/убыванию, название. Исходный массив и корзина не мутируют; неизвестная цена в конце ценовой сортировки. Смена сортировки возвращает пагинацию к 24 позициям.
- Карточки: фото без обрезки, артикул, признаки системы/типа, характеристики, цена за шт./м, доступные счётчики количества, состояние выбора. Неизвестная цена не изображается как 0 ₽, кнопка добавления для такой позиции выключена.
- Использованы существующие изображения каталога, без AI-подмены товарных фотографий. Лайтбокс: keyboard trap, Escape, возврат фокуса; резерв локального изображения при отказе внешнего источника. Для превью исправлены приоритет локальной фотографии, конфликт fallback/srcset и потеря onError до гидрации SSR.
- Корзина: фото/артикул/количество, явная подпись суммы до скидки, два варианта цены оборудования. Подсказки комплектования доступны до сетки и в корзине, но явно не объявляются полной инженерной проверкой.
- Кнопка оформления **внутри drawer теперь тоже предлагает оба пути**, а не молча выбирает equipment-only. Закрытие выбора не меняет корзину и возвращает фокус на постоянную кнопку панели. Equipment-only по-прежнему не получает потолочную стоимость.
- Не утверждается наличие по старому прайсу. Показана дата сохранённых данных и предупреждение об устаревании; отсутствие даты не заменяется текущей. SMART обозначен как маркировка каталога, не подтверждение протокола/совместимости.
- На 320 px выявлено переполнение в шапке карточек отзывов ниже каталога; добавлен перенос строки. Сами отзывы не изменены.

## Выявленный незакрытый дефект: reload каталожной корзины

**Выбор, сделанный только в каталоге без сохранённого расчёта, теряется после полной перезагрузки документа.** Корзина сохраняется при клиентских переходах сайта и открытии/закрытии drawer; это не то же самое, что persistence после reload. Исходный provider держит этот выбор в памяти. Калькуляторный черновик имеет отдельный существующий механизм, он не заменяет persistence автономной корзины.

Первый диагностический E2E с `page.reload()` подтвердил ограничение. Финальный тест явно назван «across navigation» и проверяет ровно этот контракт; проверка reload не объявлена пройденной. Для следующего технического этапа нужен versioned cart draft (SKU + quantity, без доверия сохранённым ценам), безопасное восстановление/очистка, TTL, отказ хранилища, согласование с калькуляторным черновиком и тест reload. **Закрыть до коммерческого выпуска каталога.**
