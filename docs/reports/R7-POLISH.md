# R7 · Сквозная полировка и цифровая айдентика

14 октября 2026. База: `65fdce4c4fc100971a8787e2dc1a5cea48bc0742`.
Ветка `feat/company-rebrand-v7`. Это завершённая UI-итерация в проекте, не весь v7 и не production-релиз.

## Что внедрено

- **Цифровой знак:** SVG, favicon ICO с настоящими кадрами 16/32/48 px, PNG 16/32/48/180/192/512, Apple touch icon, theme color и web manifest. Manifest имеет `display: browser`; offline/PWA-функции не обещаны. Это цифровые версии рабочего знака, не проверка товарного знака и не готовый печатный брендбук.
- **14 превью ссылок:** главная, хаб, 9 услуг, компания, управляемый свет и политика. Единая композиция 1200×630, логотип, название направления, регион/домен; JPEG 21–71 КБ, лимит 200 КБ. OpenGraph и Twitter используют одну карту маршрутов. Все 13 интерьерных обложек имеют видимую подпись «Визуализация решения»; документы — без фотографии. Это повторное использование маркированных AI-изображений, не новые объекты компании. Старые URL картинок не удалены.
- **Локальный Inter:** variable WOFF2 для латиницы/кириллицы и необходимых знаков, TTF для локальной генерации карточек. Источник, SHA256 и SIL OFL 1.1 сохранены. `next/font/local` заменяет загрузку шрифта из Google во время build; обычная сборка не требует Python или загрузки шрифта по сети.
- **404:** фирменный экран, реальные разделы и контакты; сохранены HTTP 404 и noindex.
- **Ошибка страницы:** общий визуальный компонент восстановления, явный reset и связь с компанией. Удалено «напишите мне, отвечу быстро». Нет автоматической отправки заявки, сброса storage или утверждения, что заказ сохранён. Это `app/error.tsx`, не перехват ошибок корневого layout.
- **Политика:** фирменная шапка, читабельная колонка, оглавление с 11 якорями и адаптивная сетка. Юридические абзацы сохранены побайтно (SHA256 проверяется тестом), версия согласия не менялась.
- **Отзывы:** новая сетка, аккуратная атрибуция профиля основателя и сохранённые цитаты. Профильные данные не выданы за live-рейтинг. 19 отзывов в данных профиля отделены от 16 опубликованных цитат; кнопка раскрытия использует реальную длину отображаемой подборки. Фильтр оборудования сохранён.
- **Форма на главной:** введение и контакты слева, действующая форма справа; на mobile форма идёт до дополнительных контактов. Согласие, валидация, payload, повторы, source `home` и API не переписаны. В общем ActionForm исправлена только одна формулировка «приложу» → «будет приложен».
- **Примеры работ:** более спокойные карточки, читаемые действия и окно просмотра. Фотографии, суммы, описания и пресеты существующих примеров не подменены. Добавлены удержание/возврат фокуса через существующий `useDialogFocus`, стабильный callback закрытия и передача aria-label в Button. Исправлен найденный недостаточный контраст зачёркнутой суммы в окне работы.

## Сохранённые контракты

Все прежние URL и каналы связи. Тарифы, расчётные формулы, reducer, пресеты, корзина, storage и API. Для примеров работ сохранён переход в настоящий калькулятор; для оборудования — самостоятельный путь оформления. Никаких изменений юридической модели или подтверждения SMART-совместимости.

## Границы готовности

53 DB-теста пропущены без TEST_DATABASE_URL; 12 E2E-skips — прежние device-specific ограничения. Реальные устройства, screen reader, browser zoom 200%, доставка и внешнее отображение/кэширование карточек соцсетями не проверены. Gitleaks отсутствует — успешный secrets scan не заявляется.

Остаются подтверждённые кейсы и права на старые фотографии, финальный брендбук/печатные мастера, фирменные документы, модель партнёров и договоров, EKS/BOM/SMART, server quote, security и release-gates v6/v7. Известная потеря автономной корзины при reload не исправлялась: пользователь выбрал продолжение дизайна. Современная вёрстка политики не равна юридическому согласованию её содержания.

## Сборка и передача

`npm run build:brand-identity` повторно собирает иконки и social cards из локального TTF, SVG-геометрии, `social-covers.json` и существующих оригиналов. Скрипт включён в prebuild. Реестр шрифта — `design/brand/v7/typefaces/provenance.json`.

Финальный архив этапа применяется поверх 65fdce4. Исходники, история, отчёты и конечные пакеты сохранены; промежуточные дубли очищаются только после проверки, что данные есть в архиве/обзоре.

Preview: `NEXT_PUBLIC_PREVIEW_MODE=1`, `LEAD_API_ENABLED=0`, `TELEGRAM_LEADS_ENABLED=0`, `CATALOG_LIVE_FEED2_ENABLED=0`. Для среды с 2 ГБ RAM использованы `RAYON_NUM_THREADS=1` и `NODE_OPTIONS=--max-old-space-size=1024`. Push и production-деплой не выполнялись.
