# R7 · Компания и управляемый свет

14 октября 2026, Москва. База: `e0c612e4552eeb3a42508a0f7e3fc7fbae38dd1d`.
Ветка: `feat/company-rebrand-v7`. Продолжение визуального ребрендинга по просьбе владельца; ключ для push ожидается позже.

## Реализовано

### `/o-kompanii`

Самостоятельная страница компании: интерьерный hero, подход к обсуждению проекта, четыре группы вопросов до начала работ, компактная атрибуция основателя, направления потолков и контакты. Подтверждённая модель — основатель, привлечённые мастера и партнёрские бригады. Нет вымышленного штата, ролей, стажа, числа объектов или обещания личного монтажа каждого заказа. Вместо несуществующих фото команды — инициалы основателя.

В отдельном блоке показаны существующие ФИО, НПД и ИНН из `content/contacts.ts`; новые юридические реквизиты не придуманы. Название компании не объявляется новой договорной стороной. Состав, исполнители, документы и приёмка описаны как вопросы согласования, а не как уже внедрённая CRM/операционная модель.

### `/umnoe-osveshchenie`

Самостоятельная консультационная страница: сценарии жизни → виды света → проверка комплекта → подготовка к разговору. Три переключаемые иллюстрации сценариев: каждый день, спокойный вечер, ночной ориентир. Меняются только CSS-яркость изображения и поясняющий текст. Кнопки доступны с клавиатуры, имеют `aria-pressed`, описание — `aria-live`. При reduced motion переход яркости отключён.

Демонстрация прямо названа условной. Она не изображает точный светотехнический расчёт, не переключает реальные светильники и не подтверждает функции EKS. EKS упомянут как оборудование для подбора, не как универсальная SMART-совместимость или официальный дилерский статус. Описана необходимость проверить источник света, питание, контроллер, протокол, приложение/голос, шлюз, выключатель, offline-поведение и сервисный доступ.

Новых цен, комплектов SMART, Offer/Product schema, заявлений о наличии или покупки из этой страницы нет. Ссылки ведут в действующий каталог и услуги монтажа, линий, парящих потолков и скрытых карнизов.

### Навигация и клиентский путь

- Новые страницы доступны из desktop/mobile header и footer.
- «Компания» ведёт на `/o-kompanii`; старый `/#trust` остаётся действующим разделом главной.
- На главной добавлена ссылка о компании; основной переход из блока сценариев ведёт в новый раздел света. Каталог по-прежнему доступен в header и на новой странице.
- На обеих новых страницах header и hero ведут к реальным контактам. На старых страницах header сохраняет пресеты и калькулятор.
- Исправлено назначение ссылки «Цена» для новых страниц и хаба: `/#price`, а не отсутствующий локальный `#price`. На отдельных услугах локальный раздел стоимости сохранён.
- Для консультации используются существующие телефон, Telegram, WhatsApp и email. Новая SMART-заявка в API **не создавалась**. Это намеренное ограничение: действующий ActionForm определяет `orderIntent` по составу старого расчёта; нельзя называть его типовую потолочную заявку полноценным SMART-брифом. Ссылка на стандартную форму замера на главной подписана отдельно.
- Переключение сценариев не записывает ничего в калькулятор, корзину, storage или лид. Выбранный сценарий не переносится в переписку автоматически — это иллюстрация, не сборщик комплекта.

## Визуальная система и SEO

Светлая архитектурная страница компании и тёмно-зелёный hero управляемого света с ограниченным лаймовым акцентом. Два существующих AI-изображения используются повторно, с видимой подписью; новых генераций и копий assets нет. Схемы видов освещения — декоративный CSS, не инженерные чертежи.

Страницы имеют отдельные H1, title/description, canonical, OpenGraph, breadcrumbs; у компании — AboutPage. Добавлены sitemap и карта исходников для Git lastModified; для ещё не закоммиченной новой страницы предусмотрена стабильная дата создания, не дата каждого build. Все девять прежних URL и metadata сохранены.

Стили `app/editorial-brand.css` ограничены новыми страницами и новыми ссылками. Расчётное ядро, тарифы, reducer, пресеты, cart/storage, формы, API и legal source не менялись.

## Ограничения и следующие задачи

Это завершение очередной UI-итерации, не всего v7 и не production-релиз. 53 DB-теста пропущены без TEST_DATABASE_URL; 12 E2E-skips — device-specific. Реальные iOS/Android, screen reader, доставка заявок и коммерческие данные EKS не проверены. Gitleaks отсутствует — secrets scan не заявляется выполненным.

Остаются persistence автономной каталожной корзины после reload, отдельный достоверный SMART-intent/BOM и подтверждённые функции, единицы/свежесть/остатки EKS, server quote, legal/security gates v6, подтверждённые кейсы, реальные роли и стандарты партнёров. Фото объектов и публикация фактов требуют проверки владельца. Страницы кейсов не созданы без подтверждённого материала.
