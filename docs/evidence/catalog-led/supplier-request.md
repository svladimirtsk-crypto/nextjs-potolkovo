## 3. Ленты: чего нет в данных

Серии, по которым нужен паспорт (всего 36):

- СТАНДАРТ 140
- ПРО 160
- RGB 24V
- RGBW 24V
- CCT 24V

По каждой серии просим:

- режим ленты и число электрических каналов по каждому SKU (у 33 лент одна температура К не доказывает mono)
- кратность реза (мм)
- ширина платы (мм)
- IP
- CRI и световой поток по режимам
- максимальная длина одного питания (м)
- тепловые требования (профиль, рассеиватель, закрытая полость)
- база цены: за метр или за катушку
- кратность упаковки и MOQ
- паспорт Вт/м по режимам (сейчас Вт/м выведены из названия)

## 4. Блоки питания: чего нет

Позиций в профиле: 19.

- CV/CC и точный выходной ток
- правило derating и его основание
- габариты, крепление, IP, температура
- охлаждение/шум, минимальная нагрузка
- входной диапазон, inrush и защита

Отдельно: паспорт подтверждает снижение допустимой мощности при монтаже в закрытой полости — без него коэффициент derating в расчёт не вводится.

## 5. Контроллеры и пульты: чего нет

Контроллеров: 8, пультов: 6, наборов: 3.

По контроллерам:

- предел тока по каждому каналу и суммарно (сейчас частично с этикетки)
- ограничение используемого входного разъёма
- тип выходного каскада (общий плюс/минус), распиновка
- RF-семейство и совместимые пульты (по id)
- экосистема, Алиса, зависимость от интернета, поведение после отключения питания
- версия прошивки/регион

По пультам:

- совместимые контроллеры (по id)
- число зон и число силовых каналов — раздельно
- питание пульта, сопряжение, максимум устройств
- работа без сети/офлайн

## 6. Минимальный пакет (ТЗ §12)

1. Паспорт/инструкция на каждую модель из списка выше.
2. `priceUnit` / `MOQ` / `packQty` по каждой позиции.
3. Максимальная мощность Вт/м по режимам, а не «в среднем».
4. Кратность реза, ширина платы, максимальная питаемая длина, тепловые требования.
5. Паспорт БП: выходной ток, derating и его основание.
6. Ограничения контроллера: по каждому каналу и суммарно, ограничения входного разъёма.
7. RF-семейства и подтверждённые пары «контроллер — пульт».
8. Режимы WB5 / LM051 / C01 / C02 / C03 и поведение после отключения питания.
9. Экосистема, работа с Алисой, зависимость от интернета.
10. Полная номенклатура соединителей, профилей и рассеивателей.
