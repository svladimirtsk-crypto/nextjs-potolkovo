## Как это связано с подбором БП

Наблюдения владельца (16.10.2026): WiFi-контроллеры, лента и БП EKS работают в умном доме, включая Алису. Для расчёта питания по метражу теперь есть профиль:

- мощность ленты на метр × метраж = мощность нагрузки;
- ток = мощность ÷ 24 В;
- у контроллеров указан ток на канал и суммарный — сверять с нагрузкой линии;
- запас по мощности БП — **утверждён владельцем 16.10.2026: 30 %** от нагрузки; в коде это `PSU_MARGIN_PERCENT` (`lib/lighting/led-hardware.ts`), то есть мощность БП = нагрузка × 1,3;
- пример: 12 м × 10 Вт/м = 120 Вт нагрузки → 156 Вт расчётных → по сетке 200 Вт (150 Вт меньше требуемого, поэтому не подходит);
- владелец подтвердил 16.10.2026, что Wi-Fi-контроллеры (C01, C02, C03, WB5), лента и БП из его комплекта работают в умном доме, включая Алису; статус — owner-verified по его моделям, не паспорт всего ассортимента;
- владелец подтвердил 16.10.2026, что Wi-Fi 5-в-1 (WB5) работает со всеми лентами: монохром, CCT, RGB, RGBW, RGB+CCT. Это про поддержку режимов; ток (15 А) и белый канал 5-в-1 всё равно проверяются по паспорту, поэтому для RGBW расчёт остаётся «нужна проверка».

Открытые вопросы к владельцу/поставщику: паспорт с Вт/м и IP по каждой серии; расшифровка индексов «140/160»; какие именно SKU (артикулы) проверялись с Алисой; правила продажи (метр или катушка) для каждой позиции.
