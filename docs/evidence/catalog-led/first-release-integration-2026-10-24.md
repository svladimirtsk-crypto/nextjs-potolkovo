## Оставшиеся ворота

1. Это локальная фикстура с одной ценовой дельтой, а не реальная поставка: импорт XML, `priceUnit`, `packQty`/MOQ, действительные московские остатки/резерв, паспорта, монтаж и утверждение коммерческого текста остаются открытыми.
2. Библиотечные отрицательные тесты проверяют сбой до/после switch, повреждённые/изменённые обложки и ручной rollback; этот сквозной опыт проверил **успешное** первое adoption → build → rollback. Реальную миграцию необходимо проводить через отдельный reviewed PR/CI, а не запускать прямо в production. Обновлённый workflow с build gate ещё не запускался на GitHub.
3. Указатель — атомарная публикация файлов для проверяемой сборки, но live-reader нескольких файлов должен закреплять один release ID; он не обновляет уже открытые вкладки. Отдельный разрешённый preview push и инженерный допуск обязательны до обсуждения merge/deploy.
