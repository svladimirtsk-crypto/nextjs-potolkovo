# Vercel Preview 8221214 · устранение ошибки сборки из-за абсолютных путей

**19.10.2026.** В предоставленном владельцем логе Vercel Preview сборка `feat/company-rebrand-v7-preview` на `8221214` прошла компиляцию и упала на TypeScript: архивные `docs/evidence/calculator-audit-2026-10-15/raw/extract-fixtures.ts` и `docs/evidence/stage-packages/client-materials-v8/extract-data.ts` импортировали исходники из `/home/user/repo/...`. На локальной машине такой каталог существовал, в Vercel — нет. Следующие ошибки `TS7006` возникли вслед за неразрешёнными импортами. Это не свидетельство электрической/коммерческой приёмки LED и не ошибка runtime-страниц.

**Исправление.** Импорты обоих архивных скриптов сделаны относительными от самих файлов; пути записи результатов теперь относятся к корню проекта при ручном запуске скриптов из него. Ни исторические JSON-данные, ни исходный feed не переписывались. Перед `next build` запускается `scripts/check-portable-evidence.mjs`: он отклоняет абсолютные импорты и характерные машинные пути во всех `.ts/.tsx/.mts/.cts` под `docs/evidence`. Четыре теста проверяют сам guard, в том числе прежний отрицательный случай.

Первая попытка локально запускала lint и сборку параллельно в sandbox с ~1,9 ГиБ RAM: процесс Next.js был остановлен системой (exit 137) во время компиляции. Повтор **последовательно** с ограничением памяти Node прошёл; это ограничение локальной машины, не доказательство исправления или воспроизведения иного Vercel-дефекта. Vercel сообщает машину с 8 ГиБ. **Повторная удалённая сборка после публикации исправления ещё требует проверки**; локальный build не равен зелёному deployment.

Отдельные предупреждения из лога Vercel: npm `cache-dir`/install-scripts не являлись причиной `TS2307`. Локальный `npm ci` дополнительно сообщил о 13 зависимостях с уязвимостями (4 moderate, 8 high, 1 critical); их происхождение/эксплуатация **не исследовались** в этом адресном исправлении и требуют отдельного dependency review без автоматического `npm audit fix --force`. Запасной календарь `validUntil=2026-10-05` устарел; если актуальные записи БД недоступны, блок свободных дат должен скрываться, а не показывать выдуманные даты. Нужны подтверждённые данные календаря/БД, не автоматическое продление сроков. Новые паспорта, цены и склад EKS этим фиксом не получены. Main, PR и production не затрагивать без отдельного допуска.
