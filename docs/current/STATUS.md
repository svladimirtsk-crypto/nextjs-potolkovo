## Управление документацией

Рабочими являются только документы, перечисленные в [индексе](README.md). Старые ТЗ/аудиты/поэтапные отчёты удалены из активного дерева после переноса требований. Происхождение задач сохранено в [LEGACY-MAP.csv](LEGACY-MAP.csv), перечень удаления — в [манифесте](../maintenance/DOCS-CLEANUP-V8.json).

Оригиналы пользовательских вложений не удалены. Старые технические ZIP/bundle и визуальные обзоры в рабочей среде — резервные результаты, не альтернативные действующие ТЗ. Отдельные устаревшие отчёты и копии аудитов вне Git также очищены; история репозитория не переписана.
