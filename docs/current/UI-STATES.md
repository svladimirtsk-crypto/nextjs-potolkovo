# ПОТОЛКОВО · состояния интерфейса и восстановление

14.10.2026 · B8-005. Работа только в preview. Это матрица конкретного прохода, а не утверждение о полной ручной приёмке всех устройств.

## Что внедрено

- Общий `StatePanel`: единая геометрия, фирменные поверхности/типографика, текстовое значение состояния и декоративный значок. Успех/ошибка отличаются не только цветом; live-роли используются осознанно.
- Шаг света: загрузка и ошибка больше не выдаются за пустой каталог. До получения данных соответствующее действие футера отключено. Есть явный повтор без reload и возврат к потолку.
- `useCatalogProducts` теперь подписывается на общее состояние локального индекса: один запрос для потребителей, ошибка не вызывает бесконечный автоматический retry, явное восстановление обновляет также футер и итог. Источник, декодирование товаров, цены и API не заменены.
- «Выбранное (0)» сохраняет выбранную вкладку и показывает пояснение с переходом в каталог. Прежний молчаливый переход в browse отменён как UX-несоответствие, соответствующий unit-контракт обновлён.
- Пустой поиск внутри калькулятора: явная подпись поля, пояснение, сброс запроса без очистки выбора. Внешний каталог сохраняет свой текущий контракт фильтров/корзины.
- Основная форма: фирменные error/success-панели, прежние причины отказа, таймеры, повтор и номер заявки. Сохранение в БД не названо просмотром исполнителем.
- Диалог подтверждения/rescue: короткие экраны, перенос длинных действий, прокрутка внутри ограниченного viewport, минимальные цели 44 px, подсказка телефона связана через aria-describedby.
- Клавиатурная ловушка исключает disabled/невидимые элементы. После отказа фокус на повтор ставится после commit состояния, когда кнопка включена. Во время отправки Escape не скрывает неизвестный исход.
- В неподтверждённом обещании rescue «расчёт продиктуете за минуту» оставлено нейтральное «обсудим детали расчёта». Закрытие после ошибки называется «Закрыть диалог», не обещает, что запрос не отправлялся.
- Повреждённый черновик: удаление прежней записи описано как следствие явного выбора, а не автоматическое действие.

## Матрица

| Поверхность / состояние | Ожидаемое поведение | Проверка |
|---|---|---|
| Каталог / loading | Понятная загрузка, нет ложного empty и действий с неготовыми данными | Задержка реального lazy chunk в E2E; SSR/resource unit |
| Каталог / load error | Отдельная ошибка, явный retry и возврат, не утверждение об отсутствии stock | Блокировка всех сетевых попыток до действия пользователя |
| Каталог / retry | Одна загрузка для подписчиков, без reload/смены суммы потолка | Resource unit + реальный chunk failure/recovery |
| Поиск / empty | Доступное название поля; сброс запроса не меняет выбор и смету | Unit, E2E, axe |
| Выбранное / empty | Видимая пустая вкладка, кнопка в каталог, не фиктивный итог 0 ₽ | Новый UI-контракт + unit/E2E |

## Границы

Не изменялись тарифы, формулы, серверная обработка заявок, requestId/consent, расчётный reducer, presets, URL услуг, оригинальные фото, отзывы или юридические абзацы. Нет нового SMART-BOM, серверной сметы, кейсов или исправления отложенного reload автономной корзины.

Сетевые сбои в тестах относятся к локальному чанку каталога, не к production-поставщику. В тесте учитывается штатная повторная попытка загрузчика Next/Turbopack; затем проверяется именно пользовательское восстановление. Снятие браузерной ошибки или изменение ожидания не используются вместо проверки.

B8-005 остаётся частичной до проверки оставшихся комбинаций и B8-006: реальные iOS/Android, экранная клавиатура, 200% zoom и screen reader. Автоматический axe не заменяет эту приёмку. Production-выпуск не разрешён.
