## Решения, которые нельзя откатывать случайно

- ПОТОЛКОВО — компания сегмента средний+, не обещание личного выполнения каждого заказа основателем.
- Текущая модель: основатель, привлечённые мастера и партнёрские бригады. Не выдумывать ООО, большой штат, показатели качества, роли людей или новые гарантии.
- Название/домен, все 9 страниц услуг и существующие URL сохраняются. Каталог и расчёт — действующие, а не декоративный прототип.
- Теневые/парящие потолки, световые линии и скрытые карнизы должны быть заметны до блока базовой цены.
- Не создавать второе расчётное ядро. Не выдавать AI-изображения за выполненные объекты. Цитаты реальных отзывов не переписывать.
- Ребрендинг не решает вопросы НПД/перепродажи, согласий, реальных цен/остатков, технической совместимости SMART, server quote, безопасности и доставки заявок.
- Переход на новую стратегию не изменяет автоматически договорную сторону. Фактические реквизиты требуют согласования владельца.
