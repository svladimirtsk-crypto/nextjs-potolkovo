## Деньги и правовые ограничения

Предложение не считает стоимость: суммы и позиции нужно переносить из **одной версии действующего расчёта**, затем сверять итог, скидки, включения и исключения. Тарифы, формулы сайта и API не менялись. Автоматической выгрузки расчёта с сайта этот пакет не добавляет.

Контакты взяты из `content/contacts.ts`. Реквизиты продавца/исполнителя, ИНН, гарантийные сроки, банковские данные и подписи не копировались и не выдумывались. Для продажи оборудования и новой модели исполнения нужна отдельная правовая основа по T8-005/006. Чек-лист передачи результата — не акт приёмки и не отказ от прав клиента; сервисная страница — не готовый гарантийный талон.

Перед внешним использованием: утвердить айдентику, тексты, условия замера/монтажа, исполнителя и документы; заполнить поля; сверить с источниками; проверить переносы и итоговый PDF; убрать инструкции и маркировку шаблона только после проверки. Незаполненный документ не отправлять клиенту.

## Реестр фотографий

- Шесть строк проектов — текущие примеры из `homepage.proof.items`, не подтверждённые истории компании.
- 18 фотографий — ровно gallery-массивы из `content/home-assets.ts`, а не все `proj-*.jpeg` в public.
- Размеры, байты и SHA256 прочитаны из существующих оригиналов; оригиналы не изменены. [Машиночитаемый реестр](photo-inventory.json).
- В XLSX есть миниатюры для поиска и пустые поля автора, доказательства прав, разрешённых каналов, согласий/обработки, подписи и проверки владельцем. Столбцы O–R с техническими данными скрыты, их можно раскрыть.
- Все подтверждения по умолчанию открыты, решения — «Не публиковать»/«Не согласовано». Выбор статуса в Excel не заменяет источник или правовую проверку. Автоматической публикации и case-pages нет.

Заполненные документы, клиентские данные и доказательства прав хранить в защищённой рабочей папке, не в публичном репозитории. Не перегенерировать поверх заполненных копий.

## Исходники и воспроизведение

- `templates.json` — единый текст пяти документов; `materials.css` — фирменный макет HTML/PDF.
- `source-data.json` — снимок публичных контактов и списка существующих примеров; `manifest.json` — исходные SHA и границы результата.
- Генераторы — `scripts/export-client-materials-data.ts`, `scripts/build-client-materials.py`, `scripts/export-client-materials.mjs`. Это дизайн-инструменты, не prebuild сайта.

В окружении исходного репозитория нужны Python 3 + python-docx/openpyxl/Pillow, Node, tsx, зависимости проекта и Chromium Playwright:

```bash
npx --no-install tsx --tsconfig tsconfig.json scripts/export-client-materials-data.ts
python scripts/build-client-materials.py
node scripts/export-client-materials.mjs
```

При повторном обновлении **только незаполненных исходных шаблонов** Python требует явный `--refresh-templates`. Перед обновлением сохранить заполненные копии отдельно.

DOCX использует Arial для переносимого редактирования; PDF/HTML — локальный Inter, [лицензия OFL](../../brand/v7/typefaces/OFL.txt). Логотип — из цифрового комплекта v8.1, без изменения геометрии. HTML автономен, не запрашивает сеть. PDF проверен на 10 страниц, колонтитулы и ширины 320/390/1440. DOCX проверены как OOXML; после заполнения нужны проверка в целевом Word/редакторе и повторный просмотр PDF.
