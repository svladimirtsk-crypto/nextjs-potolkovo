# ПОТОЛКОВО · цифровой комплект айдентики v8.1

14.10.2026 · B8-002 · развитие существующего знака и палитры сайта. Рабочая редакция для согласования, не новая концепция и не разрешение production-публикации.

## Состав

- [Брендбук HTML](POTOLKOVO-BRANDBOOK.html) — 10 разделов, автономный, со встроенными шрифтом и изображениями.
- [Брендбук PDF](POTOLKOVO-BRANDBOOK.pdf) — A4 landscape, для просмотра/согласования, не CMYK production art.
- `exports/` — 12 SVG и 12 прозрачных PNG: horizontal / compact / symbol × ink / reverse / black / white. SVG — буквы и знак в контурах, без внешнего шрифта. PNG шириной 1600 px (логотипы) / 512 px (знак).
- [manifest.json](manifest.json) — размеры, источник, цветовое пространство и SHA256 каждого мастера.
- `brandbook-content.html`, `brandbook.css` — редактируемые исходники макета, не самостоятельный offline-экспорт.
- [Лицензия Inter](../v7/typefaces/OFL.txt) и [происхождение](../v7/typefaces/provenance.json). Исходный знак — `components/brand/brand-logo.tsx`; геометрия сохранена. Обратная версия использует существующий lime-акцент цифровой айдентики.

## Правила

- Светлый фон: ink или black; тёмный фон: reverse или white. Прозрачный white на белом фоне закономерно не виден.
- Минимум horizontal 200 px / compact 160 px; в 16/32 px использовать существующий favicon, не логотип с мелким дескриптором.
- Охранное поле минимум четверть ширины знака от видимого контура. Не искажать пропорции и не накладывать тени.
- SVG/PNG и PDF имеют RGB-цвета. Для печати нужны профиль типографии, материал, минимальная толщина, проба и отдельная допечатная подготовка. Параметры CMYK не выдуманы.
- Утверждение владельцем и юридическая проверка обозначения ещё не выполнены. Лицензия шрифта не является заключением о правах на товарный знак.

## Воспроизведение

Только для дизайн-экспорта (не добавлено в prebuild сайта):

```bash
# Требуются Python 3 + fontTools; npm-зависимости и Chromium Playwright проекта.
python scripts/build-brand-kit.py
node scripts/export-brand-kit.mjs
```

Первый шаг создаёт SVG и автономный HTML из текущих источников, второй — PNG/манифест/PDF и проверяет адаптивность 320/390/1440, отсутствие внешних запросов и наложения контента на колонтитулы. После изменения источников повторить оба шага и визуально проверить PDF.
