# Работа с проектом

Сначала прочитайте `docs/current/README.md`. Актуальное позиционирование — компания ПОТОЛКОВО, основатель + мастера/партнёрские бригады, сегмент средний+. V7 задаёт бренд/UX; v6 остаётся технической базой и перечнем release-gates. Не возвращайте тексты про личный монтаж всех заказов.

- Сохраняйте все 9 URL услуг, точные расчётные контракты, пресеты, черновики и контекст лида. Не подменяйте действующий калькулятор макетом.
- Теневые, парящие, линии и карнизы — явные продуктовые направления.
- Не меняйте цитаты отзывов. Не выдавайте AI-иллюстрации за выполненные объекты; см. `design/brand/v7/README.md`.
- Не добавляйте выдуманные юридические реквизиты, штат, отзывы, даты доступности и SMART-совместимость.

- Проверки: lint, TypeScript/build, unit, test:flow, prebuild guards, bundle, полный Playwright. Пропуски DB без настоящей TEST_DATABASE_URL не равны успешной проверке интеграции. Axe не заменяет ручной keyboard/screen-reader/device QA.
- По результатам фиксируйте фактический объём и открытые ограничения в `docs/reports/`; не объявляйте весь v7 готовым по одной итерации.
